v3.12
  • Fixed a real gap in invoices synced to LedgerBox: your actual Work Description for each day was getting dropped, leaving only a generic "Labor: X hrs @ $Y/hr" line. Periods with no descriptions at all still show as a single combined Labor line, unchanged
  • The invoice's Notes area also now summarizes the actual work descriptions instead of just saying "Synced from ShiftLog"
